# v0.2.1 · 桌面体验与十语言支持

2026-11-13 · Windows x64 · 开发预览 · 安装包未签名

汇总 v0.2.0 桌面界面改版与 v0.2.1 质量修复；v0.2.0 没有单独的 GitHub Release。

## 更新内容

- 重整工作台外壳：可折叠导航、顶部命令面板、通知中心、可调日志抽屉和设置页。
- 提供深色、浅色和跟随 Windows 的主题；远程控制台同步使用主题颜色。
- 支持简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español、Português (Brasil)、Русский十种界面语言。
- 首次启动跟随系统语言，手动切换即时生效并记住选择；日期、数值和原生菜单随语言变化。
- 提供 Ctrl+K 命令面板、任务通知、窗口位置记忆、设置损坏恢复和减少动画选项。
- 修复浅色主题颜色、暂停任务误报完成、通知无法跳转、完成提示缺少任务信息和 Esc 未关闭命令面板的问题。
