# v0.8.7 · 一键下载开发环境

2026-11-14 · Windows x64 · 已发布开发预览 · GitHub Latest

## 更新内容

- 开发环境页在「重新检测」旁新增「一键下载」：检测缺失的开发工具后弹出本地化确认对话框，列出将要安装的工具，确认后逐个通过 winget 静默安装（`--silent --disable-interactivity`，含自动接受包与源协议），单包超时 30 分钟。
- 安装计划自动去重：npm、pip、Python launcher 由 Node.js / Python 包附带安装，cargo 由 Rustup 附带安装，不会重复安装；pnpm、yarn 在 Node.js 之后安装，并在每次安装前从注册表刷新 PATH 以满足安装期依赖。
- 安装过程实时显示进度（正在安装 2/4：Git）；完成后自动刷新 PATH 并重新检测环境，新工具无需重启 NEXUS 即被识别。
- 一键下载覆盖 15 个 winget 包：Git、GitHub CLI、Node.js LTS、Python 3.12、uv、Temurin JDK 21、Maven、Gradle、PowerShell 7、Windows Terminal、Rustup、.NET SDK 8、Docker Desktop、pnpm、yarn。
- 「重新检测」现在也会先从注册表刷新 PATH，重新检测能发现本会话之外安装的工具。
- 命令面板新增「一键下载缺失的开发工具」入口；安装结果写入活动日志，部分失败时按条目区分提示。
- 界面文案与更新日志支持现有十种语言。winget 缺失时直接提示，不会弹出确认对话框。

安装来源为 winget 官方源中的已签名发行包，不使用任意下载地址。部分机器级安装包（Git、Node.js、Python、Temurin JDK、Docker Desktop、.NET SDK 等）会弹出 UAC 授权窗口，确认对话框中已提示。功能不修改 PATH 注册表值、不下载自定义脚本。

## 已知限制

- 一键下载的真实端到端安装（点击按钮 → UAC → 安装完成 → 重检识别）尚未在真机验收；服务的安装逻辑以单元测试和真实 winget 包映射为准。
- 安装包未签名，属于 0.x 开发预览；签名与发布者身份认证按既定 SignPath 轨道另行推进。
- Docker Desktop 安装包较大且可能要求重启；winget 单包超时 30 分钟，弱网下可能失败并按失败条目提示。
- winget 不存在（如精简版系统）时一键下载不可用，重新检测与其他功能不受影响。
