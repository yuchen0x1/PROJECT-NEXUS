# v0.7.0 · 项目总览与批量托管

2026-11-13 · Windows x64 · 开发预览 · 安装包未签名

本版本汇总 v0.3.0 之后的增量改进，尚未作为 v1.0 稳定版交付。

## 更新内容

- **项目总览关系图**：账号居中，仓库环绕，连接 AI、巡检、分析、执行、测试、交付与研究。运行记录驱动连线，支持缩放、拖动、搜索、筛选、定位和查看真实输出；进入页面不会启动任务。
- **批量仓库设置**：勾选多个仓库或全选，统一设置策略，逐仓库检查与开启托管。部分失败保留成功结果，重试只处理未完成项。
- **一键教学与导航**：管理页面平铺到侧栏，七步教学支持复用已配置账号、错误重试、明确授权和暂停恢复，并引导用户找到运行结果。
- **获取模型**：填写 API 地址和密钥后读取模型列表，支持 OpenAI compatible、OpenAI、Anthropic 和 Gemini 协议；失败时可以重试或手动输入。
- **执行与交付可追踪**：分别显示执行和交付结果，交付不完整保持阻塞；保留操作意图与远端回执，支持人工核对。合并和发布前复查权限、提交及 CI 条件。
- **运行可靠性**：加入宿主和仓库租约、原子持久化与备份、有限次数后台重启，以及 Windows Job Object 进程树清理。可信仓库脚本仍需明确授权。

## 已知限制

- 当前 Windows 会话无法解密既有 GitHub 凭据及两个 AI 密钥，真实连接恢复验收为 BLOCKED。可在应用中重新连接，或回到可解密的原 Windows 会话复验；本次未覆盖原凭据文件。
- 当前凭据对 GitHub Checks API 的读取权限不足，新增 CI 门禁下的完整合并、Release 与关闭链路尚未通过真实验收。
- 非 Node 通用自动发布、研究提案自动实施、精确步骤自动续跑、NEXUS 自身跨版本自动更新、24 小时长稳和 Windows 真重启验收仍未完成。
- 本机脚本具有当前用户的文件和网络权限；程序允许列表、超时和进程树限制不构成操作系统安全沙箱。
- 安装包未配置 Authenticode 证书。逆向暴露面扫描包含误报及未覆盖项，不作为完整安全认证。
