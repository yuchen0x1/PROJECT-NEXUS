# PROJECT NEXUS 0.8.1 · 应用自动更新

**此版本只保留源码标签，未公开发布安装包。请使用 [0.8.2](v0.8.2.md)，自动更新和 Windows 兼容修复均包含在新版本中。**

2026-11-13 · Windows x64 · 0.x 开发预览 · 安装包未签名

NEXUS 现在可以检查自身的新版本，在当前页面顶部提示更新。点击「立即更新」后下载并校验安装包、保存状态、停止当前任务、自动安装，再重新打开应用。用户数据保留。

## 使用与升级

- **0.8.0 及更早版本必须先手动安装一次 0.8.1**，旧版本没有自身更新器，无法直接收到这次更新提示。
- 安装本版后，启动约 15 秒及之后每 4 小时自动检查新版本，也可从设置页点击「检查更新」。
- 支持下载进度、稍后更新、下载或校验失败后的重试；只有点击「立即更新」才下载并安装。
- 更新时会停止当前任务，不能保证任意任务自动续跑；不会清空用户数据和已保存的凭据。
- 维护者需要发布更高版本，并上传安装包与 `latest.yml`。普通源码推送不会通知客户端。
