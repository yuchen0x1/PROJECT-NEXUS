# v0.9.3 · 项目自主演进与 API 稳定性升级

**日期**：2026-11-16（Asia/Shanghai）  
**分发状态**：已正式发布：[GitHub Release v0.9.3](https://github.com/yuchen0x1/PROJECT-NEXUS/releases/tag/v0.9.3)。Windows x64 仍是 0.x 开发预览，安装包未配置 Authenticode 签名。

## 这次升级解决什么

本版把项目自主演进从一次性建议变成可复核的工程流程：先审计真实代码和运行边界，再对比开源实现，形成 36 项路线图，并将其中可安全落地的改动直接接入运行时、研究服务和首屏加载路径。

## 面向用户的变化

- API 请求现在带有追踪 ID，并统一返回安全响应头、速率保护、结构化 404/错误信息和超时预算，定位异常时可以对应到具体请求。
- 竞品研究默认覆盖 15 个候选，使用有界并发和 prompt 预算，单个来源异常不会阻塞整批研究。
- GitHub 设置页区分 PAT、GitHub App 和安装状态，避免把“已配置”误解为“已完成授权”。
- Web 与桌面入口按需加载，减少首屏初始 JavaScript 负担。
- 新增项目审计、竞品对标、升级路线图和交付报告，公开记录已完成、部分完成与外部阻塞项。
