# v2.1.1 · PROJECT NEXUS 2.1.1 — Safety Console and Deterministic Test Runs

> ⚠️ **This build is unsigned.** There is no Authenticode certificate for this
> repository, so Windows SmartScreen may warn on first run. Published under an
> explicit `publish_unsigned` owner waiver. Always verify the installer against
> `SHA256SUMS.txt` before executing it.

## Summary

PROJECT NEXUS 2.1.1 makes the v2.1.0 authorization and backup engine usable
from the application, fixes a read-only route that could never succeed, and
makes the local regression suite deterministic on developer machines.

## Highlights

- Added the **Safety & recovery** tab to the Autonomy command center. It lists
  live Action Intent grants with their scope and expiry, revokes them in one
  click, and drives backup create / verify / restore against the real local
  endpoints. No new server permission was introduced: the panel is read-only
  until an exact intent exists, exactly like the API.
- Fixed a real authorization defect: `POST /api/autonomy/backups/verify` was
  classified as a write, so verification always returned `403
  AUTONOMY_READ_ONLY` and no backup could be proven intact. Read-only verbs
  reached through `POST` are now role- and session-gated but no longer require
  a writable grant.
- Made the Vitest contract identical to CI (`maxWorkers: 1`, 60 s timeouts).
  Concurrent workers on Windows compete for the PowerShell job slots used by
  every agent Git command, which produced spurious `git clean failed
  (1073807364)` and 5 s timeout failures even though the same suite passed
  serially and in GitHub Actions.
- Ten locales carry the new strings; `npm run i18n:audit` reports 0 problems,
  0 hardcoded UI strings and 0 CSS colour findings, and coverage stays at 100%.

## Verification

- `npm run check`: typecheck, lint, 81 test files / 544 unit tests and the Vite
  production build pass.
- `npm run i18n:audit` / `npm run i18n:coverage`: 0 problems, 10 locales at 100%.
- `npm run test:desktop:centers` on real Electron 45.3.4: nine centers, all 21
  leaves, the seven Autonomy tabs and the Safety & recovery panel render from
  real API state.
- `npm run test:desktop:i18n` on real Electron: locale detection, instant
  switching, persistence, theme toggle and palette navigation pass.
- `tests/unit/autonomy-routing.test.mjs` adds an end-to-end console test:
  grant → revoke → re-grant → backup → verify → restore → audit, with no
  external request.

## Known limitations

- Installing, upgrading, interrupting and rolling back the Windows installer is
  still **NOT TESTED** without a disposable Windows VM.
- Authenticode signing is still unavailable; the installer published with this
  version is explicitly **unsigned**, and its publisher identity is unverified.
- Real AI provider write loops, 24-hour soak and deep Trivy/CodeQL/Semgrep scans
  remain unverified, as recorded in the 2.1.0 reports.

## Installing and upgrading

1. Download the installer, `.blockmap`, `latest.yml` and `SHA256SUMS.txt` from
   this release.
2. Verify the installer with `SHA256SUMS.txt` before running it.
3. Upgrades from 2.0.0/2.1.0 keep `state.json` and `autonomy.db` in place; take
   a backup from the new Safety & recovery tab before changing anything.
