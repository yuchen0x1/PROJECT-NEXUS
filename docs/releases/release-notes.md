# 发布记录

## 0.8.1 · NEXUS 应用自动更新（2026-11-13，开发预览）

Windows 安装版可在启动后及每 4 小时自动检查 NEXUS 新版本，也可从设置页手动检查。发现新版后显示全局提示，点击「立即更新」可下载、校验、保存状态、停止当前任务、自动安装并重新打开应用。支持下载进度、稍后更新、错误提示和重试，保留用户数据。

新发布流程按匹配应用版本的 `v*` 标签构建并上传安装包、blockmap 和 `latest.yml`，全部资产上传后才公开 Release。普通提交推送不触发版本通知。0.8.0 及更早客户端需先手动安装 0.8.1。真实跨版本安装重启尚未验收；未配置签名证书时产物仍未签名，不宣称具备已验证的发布者身份链。详见[本版说明与下载](v0.8.1.md)和[更新与发布说明](../APP_AUTO_UPDATE.md)。

## 0.8.0 · 新图标与协作维护（2026-11-13，开发预览）

替换为新的蓝色 N 图标，应用到 Windows 可执行文件、安装/卸载程序、窗口、托盘和应用侧栏，保留多尺寸图标与高 DPI 素材。

工作区新增协作与维护中心。六个角色分别规划、研究、开发、独立测试、安全检查和最终审查，界面展示实际模型、消息、结果和预算。开发与独立新增测试使用不同副本，完成后保留候选，不自动覆盖项目或安装。

支持安全暂停与核实检查点后续跑；项目记忆增量更新，区分来源事实与模型推测，并可查看执行经验、导出和确认清理。批准的研究提案可进入隔离实施，自我维护使用独立策略。资源中心显示实际系统、Node 和 Electron 进程指标。

更新中心提供版本检测、下载、哈希与受信发布者验证。缺少严格隔离宿主或签名安装条件时明确阻断。十语言、深浅与系统主题、高 DPI 已做本地窗口验收；完整原生安装回滚、真实外部服务及 24 小时持续验收尚未完成，安装包未签名，本次未执行安装。

详见 [版本说明与下载](v0.8.0.md)和[交付状态](../FINAL_DELIVERY_REPORT.md)。

## 0.7.0 · 项目总览关系图（2026-11-13）

工作区新增「项目总览」。账号位于中心，仓库分布四周，内圈显示 AI、巡检、规划、执行、测试、交付与研究。运行任务驱动对应连线流动，点击节点可查看模型连接、相关任务、近期输出以及执行和交付结果。

支持缩放、拖动画布、显示全图、搜索、状态筛选和仓库定位。约每 3 秒读取后台记录；等待审批、任务完成、后台隐藏或连接中断时停止相应动画。断线保留上次数据并明确提示，打开页面不会启动仓库任务。

使用方法见 [中文上手指南](../QUICK_START.zh-CN.md)，验收见 [交付记录](../PROJECT_OVERVIEW_REPORT.md)。

此版本汇总 0.3.0 之后的项目托管、交付状态、一键教学、模型选择和批量设置改进。Windows x64 安装包、校验值与已知限制见 [0.7.0 版本说明](v0.7.0.md)和 [GitHub Release](https://github.com/yuchen0x1/PROJECT-NEXUS/releases/tag/v0.7.0)。仍为 0.x 开发预览，安装包未签名；当前 Windows 会话中旧 GitHub / AI 凭据解密未通过，不代表真实服务连接验收通过。

## 0.6.0 · 多仓库批量托管（2026-11-13，本地未发布）

仓库选择改为多选列表，支持「全选」「全不选」、搜索和已选数量。全选与全不选作用于全部已同步仓库，搜索不会丢失已选项，自动刷新也不会重新勾选已经取消的仓库。

后续统一策略、检查、开启托管和立即检查 Issue 均应用于全部所选仓库，逐仓库显示进度、成功与失败。部分失败保留成功结果，重试仅处理未完成项；未选仓库保持原配置。大批量操作可以停止后续请求，开启时刷新过期的检查凭证。

使用方法见 [中文上手指南](../QUICK_START.zh-CN.md)，验收见 [交付记录](../BATCH_REPOSITORIES_REPORT.md)。实际修复和交付仍按仓库策略及检查结果执行；研究升级提案仍需审阅。

## 0.5.1 · 获取并选择模型（2026-11-13，本地未发布）

配置 AI 时，默认模型旁提供「获取模型」小按钮。填写 API 地址和密钥即可读取模型列表，从下拉菜单选择后填入默认模型，无需先保存。已有连接可以复用已保存的密钥。

接口不支持、权限不足、网络失败和超时会显示对应提示，可以重试或继续手动输入。切换地址、密钥或 API 类型会清除旧列表；修改地址或类型后需重新填写密钥。模型最终是否可用仍由「保存并测试」验证。

使用方法见 [中文上手指南](../QUICK_START.zh-CN.md)，验收见 [交付记录](../MODEL_PICKER_REPORT.md)。

## 0.5.0 · 一键教学与平铺导航（2026-11-13，本地未发布）

管理功能全部平铺在主侧栏，直接点击即可。工作台和顶部提供「一键教学」，每一步说明位置、填写内容和完成条件；填写后下一步会保存、检查并自动切换。

已有连接可直接复用，失败可以原地重试。开启自动任务前，教学要求明确授权并检查全局巡检是否暂停。完成后会带用户找到托管、任务、Issue 和研究结果，显示实际状态。

使用方法见 [中文上手指南](../QUICK_START.zh-CN.md)，验收见 [交付记录](../GUIDED_SETUP_REPORT.md)。自动维护与待审阅升级提案的范围在教学中明确说明。

## 0.4.0 · 按序升级预览（2026-11-13，本地未发布）

GitHub 连接步骤新增“获取 GitHub 访问令牌”链接，点击后在默认浏览器打开 GitHub 官方创建页面。

任务中心分别显示执行和交付结果，发布失败不再显示整项成功。撤销权限后停止后续写入；设置向导切换仓库后重新检查。

中断任务保留操作意图与回执，可核对真实结果。脚本默认禁止，明确授权可信仓库后才运行。后台限制连续重启次数，并清理宿主退出时的子进程。

合并前核对 GitHub CI 与提交，发布前保存计划。研究提案附源码证据，采用前审阅许可证。全部远程页面统一进入桌面侧栏，并提示待审批操作。

此版本仍为本地预览。非 Node 打包、签名证书、24 小时长稳与真实跨版本自动更新未完成验收，详见 [按序升级报告](../ORDERED_UPGRADE_REPORT.md)。

## 0.3.0 · v1.0 开发预览（2026-11-13，本地未发布）

七步引导帮助用户连接 GitHub、配置 AI、选择仓库和开启自主维护。凭据在本机加密保存，重启恢复。轻量监控无需下载代码，修复时创建独立工作区。

此预览尚未满足 v1.0 全部验收条件，未作为稳定版发布。详见 [交付报告](../V1_DELIVERY_REPORT.md)。
