## v0.8.2 · 应用自动更新

2026-11-13 · 开发预览

Windows 安装版可在启动后及每 4 小时自动检查 NEXUS 新版本，也可从设置页手动检查。发现新版后显示全局提示，点击「立即更新」可下载、校验、保存状态、停止当前任务、自动安装并重新打开应用。支持下载进度、稍后更新、错误提示和重试，保留用户数据。

修复部分 Windows 环境下任务命令启动超时的问题：保留 PowerShell 模块发现所需的路径，仍过滤 GitHub、AI 和其他凭据环境变量。新发布流程按匹配应用版本的 `v*` 标签构建并上传安装包、blockmap 和 `latest.yml`，全部资产上传后才公开 Release。

普通提交推送不触发版本通知。0.8.0 及更早客户端需先手动安装 0.8.2。真实跨版本安装重启尚未验收；未配置签名证书时产物仍未签名，不宣称具备已验证的发布者身份链。详见[本版说明与下载](v0.8.2.md)和[更新与发布说明](../APP_AUTO_UPDATE.md)。

## v0.7.0 · 项目总览与批量托管

2026-11-13 · 已发布开发预览

工作区新增「项目总览」。账号位于中心，仓库分布四周，内圈显示 AI、巡检、规划、执行、测试、交付与研究。运行任务驱动对应连线流动，点击节点可查看模型连接、相关任务、近期输出以及执行和交付结果。

支持缩放、拖动画布、显示全图、搜索、状态筛选和仓库定位。约每 3 秒读取后台记录；等待审批、任务完成、后台隐藏或连接中断时停止相应动画。断线保留上次数据并明确提示，打开页面不会启动仓库任务。

使用方法见 [中文上手指南](../QUICK_START.zh-CN.md)，验收见 [交付记录](../PROJECT_OVERVIEW_REPORT.md)。

此版本汇总 0.3.0 之后的项目托管、交付状态、一键教学、模型选择和批量设置改进。Windows x64 安装包、校验值与已知限制见 [0.7.0 版本说明](v0.7.0.md)和 [GitHub Release](https://github.com/yuchen0x1/PROJECT-NEXUS/releases/tag/v0.7.0)。仍为 0.x 开发预览，安装包未签名；当前 Windows 会话中旧 GitHub / AI 凭据解密未通过，不代表真实服务连接验收通过。

## v0.6.0 · 多仓库批量托管

2026-11-13 · 本地预览，变更已收录 v0.7.0

仓库选择改为多选列表，支持「全选」「全不选」、搜索和已选数量。全选与全不选作用于全部已同步仓库，搜索不会丢失已选项，自动刷新也不会重新勾选已经取消的仓库。

后续统一策略、检查、开启托管和立即检查 Issue 均应用于全部所选仓库，逐仓库显示进度、成功与失败。部分失败保留成功结果，重试仅处理未完成项；未选仓库保持原配置。大批量操作可以停止后续请求，开启时刷新过期的检查凭证。

使用方法见 [中文上手指南](../QUICK_START.zh-CN.md)，验收见 [交付记录](../BATCH_REPOSITORIES_REPORT.md)。实际修复和交付仍按仓库策略及检查结果执行；研究升级提案仍需审阅。

## v0.5.1 · 获取并选择模型

2026-11-13 · 本地预览，变更已收录 v0.7.0

配置 AI 时，默认模型旁提供「获取模型」小按钮。填写 API 地址和密钥即可读取模型列表，从下拉菜单选择后填入默认模型，无需先保存。已有连接可以复用已保存的密钥。

接口不支持、权限不足、网络失败和超时会显示对应提示，可以重试或继续手动输入。切换地址、密钥或 API 类型会清除旧列表；修改地址或类型后需重新填写密钥。模型最终是否可用仍由「保存并测试」验证。

使用方法见 [中文上手指南](../QUICK_START.zh-CN.md)，验收见 [交付记录](../MODEL_PICKER_REPORT.md)。

## v0.4.0 · 按序升级预览
