# PROJECT NEXUS 0.8.0 · 新图标与协作维护

2026-11-13 · Windows x64 · 0.x 开发预览

本版采用新的蓝色 N 图标，统一用于 Windows EXE、安装器、卸载器、窗口、托盘、应用侧栏与网页图标。提供 16、32、48、64、128、256 像素 Windows 图标，侧栏适配高 DPI；原始图标和 PNG 母版保留在源码中。

## 新功能

- 新增协作与维护中心，展示规划、研究、开发、独立测试、安全和审查六角色的实际模型、消息、结果及预算。
- 开发和独立新增测试分别使用隔离工作区；支持安全暂停、检查点确认续跑和进程异常退出后的记录恢复。
- 批准的源码研究提案可进入隔离实施候选，自我维护使用独立策略与确认门禁。
- 项目记忆支持增量理解、来源与推测区分、执行经验、查看、导出和确认清理。
- 资源中心展示系统、Node 和 Electron 指标；更新中心支持版本检测、下载、摘要与发布者核验。
