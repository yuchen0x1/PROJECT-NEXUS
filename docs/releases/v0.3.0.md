# v0.3.0 · 自主开发引擎

2026-11-13 · Windows x64 · 开发预览 · 安装包未签名

引入多轮自主开发引擎：从计划、工具执行到验证、有限修复与独立审查，任务过程可追踪。

## 更新内容

- Agent 可生成持久化计划，执行文件与 Git 操作，运行测试/构建，并根据真实失败进行有限次数修复。
- 提供 34 项工具、权限与审批、迭代/Token/耗时预算、取消和事件记录。
- Git 项目采用独立 Worktree，其他项目采用受边界限制的快照；支持任务或文件回滚，确认应用前备份原文件。
- 项目分析可索引文件、符号、依赖、入口和测试，为任务选择有限且脱敏的上下文。
- 提供多 Provider 管理、连通测试、路由和费用估算；桌面密钥由 Windows DPAPI 加密保存。
- Agent 工作台展示计划、验证、审查、审批和应用/回滚入口，覆盖十种界面语言。
