## 4. 客户端无法解决的问题

ASAR 可读取、同一 Windows 用户权限下的恶意脚本、DPAPI 的权限边界和提供方计费准确性，不因替换图标而改变。哈希只能核对文件，不能认证发布者；本版没有签名证书，也没有宣称具备完整 OS 沙箱或可靠自动安装回滚。
