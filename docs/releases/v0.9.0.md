## 1. 这次升级解决什么

v0.8.9 之前，NEXUS 已有 GitHub 同步、Issue 修复流水线、Codex app-server 桥接、隔离工作区与发布路由，但缺少：

- 一个不依赖页面、可持久恢复的自治调度中心；
- 对已安装、已登录的 **桌面 AI 编程客户端** 的统一接入（原有 `codex-desktop-assist` 明确是 assist-only，禁止任务注入）；
- 把「AI API 未配置 / 桌面客户端未连接 / 扫描未完成 / manifest / 任务未生成 / 任务不可执行」分开的精确诊断；
- 增量事件去重、Issue 生命周期、同类项目移植分析与许可证判断。

v0.9.0 通过新增独立运行时补齐这些能力，**不是重设计现有页面**。

## 2. 新增内容

### 2.1 运行时底座

| 模块 | 文件 | 内容 |
| --- | --- | --- |
| 持久化 | `server/autonomy/db.mjs` | SQLite schema v2、迁移表、16 个集合、append-only 审计、JSON 降级 |
| 领域模型 | `server/autonomy/model.mjs` | P0–P4、任务状态机、16 态桌面执行状态、Issue 9 态、6 类阻断码、脱敏 |
| 调度 | `server/autonomy/engine.mjs` | 编排、优先级、并发、同仓写锁、客户端占用、幂等、退避、超时、恢复、overview |
| REST + ticker | `server/autonomy/api.mjs` | `/api/autonomy/*` 全部端点、60 秒服务进程 ticker |
| 接入 | `server/index.mjs` | 追加一次注册（隔离 try/catch，失败不影响既有服务）与启动时 tick |

### 2.2 监控与智能

- `monitor.mjs`：13 类资源、ETag 条件请求、游标、事件指纹去重、分页、429/403 退避、Webhook 规范化与自动回退、Issue 证据链（timeline / PR / reviews / compare / comments / Actions）。
- `intelligence.mjs`：精确就绪诊断、GitHub Search 同类项目发现、真实 release/commit/issue/PR 跟踪、12 项移植分析、许可证兼容矩阵。

### 2.3 桌面 AI 客户端

- `desktop/adapters.mjs`：统一 Desktop Agent Adapter 接口；ChatGPT Desktop、WorkBuddy、Codex CLI、Generic 四个适配器；独立能力检测表；项目归属强制校验；幂等发送；失败截图；人工接管与恢复。
- `desktop/uia.mjs` + `desktop/uia-driver.ps1`：Windows UI Automation 驱动，按窗口标题/进程名与 AutomationId/Name/ControlType 定位，不用坐标、不用固定 Sleep；控件找不到即停止；长任务包走 UTF-8 文件。
- `task-package.mjs`：完整结构化任务包 + 双重凭据检查。

### 2.4 执行、验收与发布

- `workspace.mjs`：Git Worktree 隔离、脏工作区拒绝、diff 范围审查。
- `reviewer.mjs`：按项目真实配置探测命令、程序白名单执行、独立 PASS/FAIL、版本计算、CHANGELOG、9 项发布门禁。

### 2.5 界面

- `src/desktop/AutonomyCenter.tsx` + `autonomy.css`：深色科技风指挥中心，12 项真实指标、全局开关与 6 个立即动作、六个页签，数据全部来自 REST。
- `src/App.tsx` 新增导航项；10 个语言 `git.json` 增加 `shell.nav.autonomy`。

## 5. 已知限制（重要）

- **未端到端验证**向真实已登录客户端发送任务并让其修改代码：控件级自动化标为 `partial`，默认走人工接管；结果由 Git diff + 测试独立验收。
- **应用自动发布链路未端到端闭环**：应用本身未自动创建 PR、合并或在应用内创建 Release；自动写入默认关闭，需显式授权与 9 项门禁。本版 GitHub Release 由开发者按用户明确指令在应用外部通过 `git push` 与 GitHub REST API 手动发布，**不代表应用自动发布能力已验证**。
- **未集成** CodeQL / Semgrep / Gitleaks / Trivy / npm audit 等外部安全工具。
- **未做** 24 小时连续浸泡运行。
- 新增指挥中心为中英双语文案（十语言仅覆盖导航标签）。
- `node:sqlite` 在 Node 22 为实验特性，已有 JSON 降级。

完整列表见 [已知限制](../AUTONOMY_V2_LIMITATIONS.md)。

## 6. 升级与兼容

- 无需迁移：`data/state.json` 保持 schema v4，新数据写入独立的 `data/autonomy.db`。
- 无需新增依赖：只用 Node 内置 `node:sqlite`。
- 无需重新配置 AI API：桌面客户端模式独立工作。
- 打包配置：`server/autonomy/desktop/uia-driver.ps1` 已加入 `asarUnpack`。
- 若新数据库后端初始化失败，接入代码会捕获并记录错误，**既有工作站继续运行**。
