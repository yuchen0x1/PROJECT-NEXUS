# v0.8.4 · 归档仓库筛选与状态标记

2026-11-13 · Windows x64 · 本地开发预览 · 尚未公开发布

## 更新内容

- 托管仓库列表默认隐藏已归档项目。每行右侧显示「正常更新」或「已归档」，可切换「显示已归档」查看历史仓库。
- 归档行不可勾选；默认选择、全选、已选数量及确认只针对可托管仓库。搜索和显示开关保留有效选择。
- GitHub 同步保留归档状态；已选项目新归档后自动取消选择，全部归档时明确提示。解除归档并同步后可重新选择。
- 确认及批量操作前复查选择，后端在开启托管前再次读取 GitHub 状态，避免旧列表误启用刚归档的仓库。
- 状态标签和提示支持现有十种语言；应用内更新日志同步增加本版摘要。

「正常更新」表示仓库未归档，不表示当前正在执行更新任务。已有仓库记录和策略保留，不在 GitHub 上执行归档或解除归档操作。

## 使用方法

安装新版后打开「选择仓库」，点击一次「同步 GitHub」，让旧记录补齐最新归档状态。默认只显示可托管仓库；需要查看归档记录时勾选「显示已归档」。归档或解除归档后再次同步即可刷新。

## 已知限制

- 旧记录需要同步 GitHub 才能获得最新归档状态；列表不通过“最近提交时间”推测归档。
- 归档状态变化不会自动取消已经运行中的任务或删除既有托管策略。
- 本版未覆盖当前用户安装目录，也未验收真实跨版本自动安装重启。
