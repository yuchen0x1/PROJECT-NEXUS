# v0.8.6 · 首次启动自动教学

2026-11-14 · Windows x64 · 本地开发预览 · 尚未公开发布

## 更新内容

- 新用户第一次启动应用会自动打开教学，无需自行寻找入口。
- 沿用七步操作说明：连接 GitHub、配置 AI、选择仓库、检测工具、设置策略、检查仓库和确认开启托管。每一步标明功能位置及预期结果，失败可原地重试。
- 完成配置后，继续介绍托管、任务中心、Issue 与研究，帮助客户找到运行状态和结果。
- 提供「稍后继续」；关闭未完成的教学后，下次启动再次引导。设置已完成而功能导览未完成时，重启进入功能导览。
- 全部教学完成后保存状态，后续启动不再自动弹出。工作台、顶部和命令面板保留「一键教学」，可随时重看。
- 完成状态保存在桌面设置中，不依赖浏览器缓存；语言和主题切换保留该状态。新增提示与版本日志支持十种语言。

教学沿用既有的连接、检查和显式授权流程。打开教学不会自动启用仓库托管或替客户勾选脚本执行、远程写入授权。

## 已知限制

- 旧版尚未保存教学完成状态的用户升级后也会显示教学，完成后不再自动弹出。
- 设置阶段重新进入时从连接步骤开始，复用有效连接；不保存尚未提交的密钥输入，也不自动跳过仓库与授权检查。功能导览重新进入时从第一个页面开始。
- 新版需要安装后生效；真实跨版本自动安装、重启与回滚未验收。
