# v0.9.5 · Windows 桌面发布完整性修复

## 版本概述

本补丁分离 Windows 安装包构建与 GitHub 发布权限。发布前核对 tag 对应的源码、可信 Windows 签名和四份资产的远端摘要；遇到中断可使用原构建产物继续同一草稿，不会覆盖现有资产，也不会公开不完整的 Release。

## 更新内容

- PR 可构建并核验 Windows 候选产物，不会创建 GitHub Release。手动触发默认也只校验。
- 正式发布阶段绑定默认分支上的稳定版本 tag，要求可信 Authenticode 签名，串行检查公开版本号。
- 校验安装包、blockmap、`latest.yml` 和 `SHA256SUMS.txt` 全部上传且与本地产物一致，随后才发布草稿。
- 包含上游主分支已合并的 GitHub App 不透明安装令牌脱敏修复。

## 安装与验证

只有 GitHub Release 最终公开并包含四项资产后才可下载。下载 Windows x64 安装包后，对照 `SHA256SUMS.txt` 执行 `Get-FileHash -Algorithm SHA256 <installer>`，并在 Windows 查看有效的发布者签名。安装包签名和摘要检查不等于由旧版升级与失败回滚验收；请勿把未发布构建当成更新通道。
