## 保护边界

应用主进程设置 contextIsolation/sandbox、受认证回环服务、同源 IPC、CSP；Preload 不暴露 Node。凭据库在用户数据目录，运行命令过滤凭据变量。新功能采用单独、版本化 JSON 文件，不改变已有 schema v4，不自动恢复备份覆盖原数据。

当前仓库没有声明项目许可证，因此不能只凭竞品为 MIT/Apache 就宣称可直接兼容复制。本次仅读取并参考设计，独立编写实现，不拷入外部代码或运行第三方脚本。
