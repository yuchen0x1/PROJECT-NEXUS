# 资源与长期运行报告

日期：2026-11-13。总体 PARTIAL；真实资源采集、索引增量复用和准入已有验证，24 小时持续验收仍在进行。

## 已实施与计量边界

资源中心读取实际系统 CPU 差值、物理内存、数据盘可用空间、Node RSS/heap/运行时长及进程 I/O 操作计数。受信 IPC 提供 Electron 主进程、Renderer 和其他 Electron 进程的实际 CPU/工作集；UI 展示真实队列、已记录模型请求、已知/未知 token 和可用时的费用估算。

磁盘空间未知或低于 1 GiB 时阻止新增协作任务；低空闲内存或 CPU 超过 90% 时降为一个并发角色。协作队列最多两个活跃工作流，角色并发有上限。普通脚本仍受既有命令超时、输出、进程数和 Job 内存限制。

网络当前标为未探测，不把浏览器 online 当作模型/GitHub 可达证明。Node fsRead/fsWrite 是操作计数，不是磁盘吞吐。长稳 harness 的 Windows CIM 进程 I/O 字节计数也不是物理磁盘设备吞吐。旧本地任务和托管队列仍有各自固定限额，尚未统一为全应用资源调度；任务优先级也未完整实现。

索引现在基于绑定根目录、文件大小/mtime 和已有源码摘要复用解析结果，不先全量分析再计算增量。测试的第二次未变化刷新 `analyzedFiles=0`、`reusedFiles=1`。元数据缓存不能对抗刻意保持 size/mtime 的恶意修改，关键交付指纹仍读取实际字节。

## 24 小时持续测试

`node tests/evolution-soak.mjs` 默认真实运行 24 小时。每小时创建一个隔离 fixture 协作任务，每分钟记录 API/Electron/Renderer 内存、Windows 进程树、句柄、进程 I/O 和队列。测试使用独立 profile、固定源码快照及已锁定依赖，不访问原用户凭据或写入真实 GitHub。窗口在采样间隔隐藏，属于轻负载后台测试。

原始 `manifest.json`、`status.json`、`samples.jsonl` 和 `jobs.jsonl` 保存在 `test-results/soak/<实际启动时间>/`。状态只有满足实测时长、采样连续性、无记录错误及源码未漂移才可变为 PASS。短测试明确标为 PARTIAL，故障测试标为 FAIL；不能把计划中的 24h 或短测折算为完成。
